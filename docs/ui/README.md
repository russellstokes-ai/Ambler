# Ambler UI Phase

Updated: 2026-10-07

This folder is the canonical design specification for the Draftbit-first UI phase.

Important status distinction:
- the UI **specification** is complete for Sprints 0–8
- Draftbit implementation and owner UI testing are **not yet complete**
- GitHub remains the product/design source of truth
- approved Draftbit layouts must be reflected back into these documents before major engineering resumes

## Target checkpoint

The Draftbit prototype should contain **36 primary screens** plus the required overlays/states and support the five test journeys in Sprint 8.

The major UI is considered locked only after owner testing on compact phone and fold-open layouts.
