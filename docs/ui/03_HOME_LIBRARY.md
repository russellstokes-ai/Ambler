# Ambler UI Sprint 3 — Home + Story Library

Status: design specification complete
Updated: 2026-10-07

## 5. Home

Purpose: answer “what is happening now, and what can I relive?”

Sections:
1. greeting/profile affordance
2. active event hero, if any
3. upcoming events
4. recent stories
5. continue reliving, if story progress exists

Active event hero:
- cover
- event name
- live/upcoming state
- participant count
- moment count
- primary action: Open Event

Completed story tile:
- cinematic cover
- title/date/location
- subtle storage badge: Device / Cloud / Home Server
- progress if partially viewed

Empty Home:
- concise value proposition
- Create first event
- optional “Join with invite”

## 6. Events

Tabs/segments:
- Active
- Upcoming
- Past

Rows use event identity, date/status and participation data.
Do not present events as generic admin cards.

## 7. Stories Library

Visual-first cover grid/list.

Filters:
- All
- Trips
- Celebrations
- Activities
- Family/Life
- Year
- Storage location

Search:
- title
- place
- participant where indexed and privacy-safe

Story actions:
- Relive
- Share
- Save/Move to server
- Archive

## 8. Archive

Archived events/stories are visually subdued.
Actions:
- Restore
- Delete permanently

Permanent delete explains whether original media/server copies will also be removed.

## Fold-open

Home:
- active event can occupy left hero pane
- recent stories on right

Stories:
- wider multi-column cover wall
- maintain fixed cover aspect ratios

## Sprint 3 acceptance

- active work and finished stories are visually distinct
- story library feels like a personal media collection
- hosting location is visible without becoming technical
- empty and large-library states both work
