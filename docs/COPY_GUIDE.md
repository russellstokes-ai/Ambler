# Ambler Copy Guide

## Voice and Tone

Ambler sounds warm, polished, and human. The app should feel like a thoughtful host who knows the event matters.

- Lead with the outcome: a beautiful storybook, a shared memory, a route worth reliving.
- Keep mobile copy short. One clear sentence is better than two clever ones.
- Use natural words: guests, people, moments, story, journey, keepsake, route, map.
- Prefer sentence case for buttons and compact labels.
- Avoid technical explanations unless the user needs them to act.

## Approved Phrases

- Create an event
- Create storybook
- Open storybook
- Share invite
- Add details to continue
- Route Replay only runs for this event
- Your storybook is ready
- Moments added
- Places in the story
- Send it to the group
- Keep a copy

## Banned Phrases

Do not use these in user-facing copy:

- AI
- artificial intelligence
- machine learning
- algorithm
- automated
- tracking
- surveillance
- monitoring

Avoid these in location contexts:

- capture your location
- location tracking
- monitor your route
- always on
- background tracking

Use instead:

- Route Replay adds places only for this event
- Use my location for this event
- You can pause or stop whenever you like
- Your full route stays inside the event

## Theme-Aware Copy

Theme voice should change the flavour without changing the product promise.

- Cinematic: emotional, spacious, story-led. Use "the story", "the moments", "worth reliving".
- Social Story: quick, playful, group-facing. Use "recap", "send it", "top moments".
- Wrapped: stat-led and energetic. Use "by the numbers", "top", "total", "biggest".
- Route Replay: journey-first. Use "route", "stops", "detours", "journey".
- Luxe: restrained and elegant. Use "evening", "curated", "distinction", "remember".
- Retro Film: nostalgic. Use "reel", "prints", "throwback", "saved on film".
- Magazine: editorial. Use "feature", "spread", "portfolio", "details".
- Chaos: funny but not crude. Use "recap", "detours", "wild", "send it to the group".
- Family Keepsake: gentle and warm. Use "keep", "family", "together", "treasure".
- Minimal: plain and quiet. Use short labels and factual subtitles.

## Event-Type Copy

Event type should override generic theme copy when the occasion has specific expectations.

- Road trip: road, route, stops, scenic detours, journey.
- Wedding: day, ceremony, celebration, guests, first dance, memories to keep.
- Festival: stages, crowds, weekend, lights, setlist, grounds.
- Birthday: celebration, candles, cheers, favourite moments.
- Family gathering: together, family, keepsake, little moments.
- Proposal: the moment, the yes, the start of the story.
- Night out, stag, hen: high energy, group quotes, playful recap. Keep it inclusive.

Do not let road-trip copy leak into weddings or family events. Do not let night-out copy leak into proposals or weddings.

## Error Messages

Errors should be calm, specific where possible, and actionable.

Pattern:

- Title: what did not work.
- Body: what the user can do next.
- Button: Try again, Save again, or Go back.

Examples:

- Storybook not ready. We could not build this storybook. Try again in a moment.
- We could not create this event. Check the details and try again.
- Sign-in did not work. We could not sign you in. Try again.

Avoid:

- Something went wrong
- Failed
- Unknown error
- Stack traces or service names

## Empty States

Empty states should invite the next action without sounding like a warning.

Pattern:

- Title: current state.
- Body: one sentence that points to the next meaningful action.

Examples:

- No events yet. Create your first event, invite your people, and start gathering moments.
- No moments yet. Be the first to share a moment from this event.
- No route for this story. Route Replay was not turned on for this event.

## Location Consent

Location copy must feel explicit and respectful.

- Say when it runs: only for this event.
- Say who can see it: inside the event, organiser for the full route.
- Say control is available: pause or stop whenever you like.
- Never imply passive or hidden collection.
