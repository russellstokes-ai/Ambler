# Ambler Play Store Screenshot Plan

Google Play allows up to 8 phone screenshots. Screenshots must be at least 320 px wide and no more than 1080 px wide. Use polished Android device frames only if they do not reduce readability.

Recommended format:

- Portrait phone screenshots
- 1080 px wide export when possible
- Consistent status bar treatment
- Short captions over clean top or bottom bands
- Use real-looking event content from the demo build
- Avoid unsupported claims

## 1. Onboarding / Product Promise

Shows: The first onboarding screen or opening screen with Ambler branding and a premium event recap visual.

Highlight: Ambler turns shared moments into storybooks for any event.

Caption: "Turn any event into a storybook"

## 2. Event Creation

Shows: Create event flow with event name, date, event type, and theme selection.

Highlight: Fast setup for birthdays, trips, weddings, parties, festivals, and more.

Caption: "Create a loop for any occasion"

## 3. Theme Selection

Shows: Theme picker with multiple visual styles and previews.

Highlight: Users can shape the mood and visual style of each event.

Caption: "Choose the mood of the moment"

## 4. Event Lobby / Invite

Shows: Event lobby with QR invite, participant list, and event status.

Highlight: Shared events bring everyone's moments into one place.

Caption: "Invite your people in seconds"

## 5. Media Gallery

Shows: Event gallery with selected photos and videos laid out beautifully.

Highlight: Photos and videos are organized around the event, not lost in a camera roll.

Caption: "Bring every best shot together"

## 6. Route Replay

Shows: Map or route page from the storybook with stops and movement.

Highlight: Optional event routes add context for trips, days out, and multi-stop events.

Caption: "Relive where it happened"

## 7. Storybook Viewer

Shows: A polished storybook page with animated layout, hero image, caption, and theme styling.

Highlight: The core product experience: premium event recap pages.

Caption: "Watch the recap come alive"

## 8. Share / Final Storybook

Shows: Share page, final storybook cover, or completed recap summary.

Highlight: Users can revisit and share the finished event story.

Caption: "Share the story with everyone there"

## Capture Notes

- Use the strongest demo event available, such as a trip or celebration with varied photos, map moments, and group context.
- Keep captions short and readable on small screens.
- Avoid showing placeholder copy, debug UI, mock labels, or incomplete settings.
- Avoid showing private emails, real full names, precise home addresses, or sensitive locations.
- Confirm that any location screenshot represents an event route and not a private residence.
- Use screenshots from a build with final colors, app icon, and splash screen applied.

## Optional Alternate Screens

If one of the 8 key screens is not ready, replace it with:

- Privacy controls screen
- Event type library
- Storybook highlights page
- Reactions and captions screen
- Settings screen with account and deletion controls
