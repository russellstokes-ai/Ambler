# Ambler Storybook Quality Standard

The storybook is the key selling point.

Every engineering and design decision should improve one of these:

1. Visual impact
2. Narrative flow
3. Photo selection quality
4. Timeline clarity
5. Route Replay usefulness
6. Story Insights usefulness
7. Shareability
8. Emotional value

## Minimum commercial-quality storybook

A generated storybook must include:

- A cinematic cover that looks worth opening
- A strong opening page
- Timeline built from timestamps
- Route Replay with map, route line and photo pins
- Hero gallery with best photos
- Story Insights with useful stats
- Friend captions or quotes
- Share page with recap card options

## Quality scoring

Each storybook gets a quality score:

- Visual impact: 0–100
- Narrative flow: 0–100
- Photo diversity: 0–100
- Timeline completeness: 0–100
- Route completeness: 0–100
- Shareability: 0–100

The app should not present a weak storybook as final. If score is low, it should ask the organiser to add more photos, captions or location data.

## UI language

Use:
- Story Insights
- Vibe Stats
- Smart Recap
- Route Replay
- Memory Highlights

Avoid technical or invasive-sounding labels in consumer UI.
